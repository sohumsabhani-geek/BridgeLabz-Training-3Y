Responsive Design Principles

Fluid Layouts

Flexible widths help a page fit different screens.

.container {
  width: 90%;
  margin: auto;
}

Flexible Media

Images should fit inside their containers.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Media queries can change the layout when needed.

@media (max-width: 600px) {
  .cards { grid-template-columns: 1fr; }
}
