Responsive CSS Cheat Sheet

Some useful CSS concepts

Filters

Change the look of an image.

filter: grayscale(100%);

Media Queries

Apply styles for a screen size.

@media (max-width: 700px) { }

Responsive Design

Make a page fit different devices.

max-width: 100%;

Typography

Set text size that can change.

font-size: clamp(1rem, 2vw, 1.5rem);
